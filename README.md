# 经纬推演 · POLISCOPE

一个中文政治经济情景模拟器。从十种现实制度组合出发，逐年观察政策选择对经济与治理指标的影响。

[现有在线网站](https://zh-polity-economy-lab.wholeanchovy16.chatgpt.site/)

## 可以做什么

- 在十种制度案例之间切换，查看制度简介、参数和参考来源。
- 选择公共投资、福利、税收、透明度、技能培养、公众协商等政策，调整实施力度和外部环境。
- 推进模拟年份，查看实际产出、消费价格、公众信任等趋势，以及政策影响和决策记录。
- 在当前浏览器中保存各制度的推演进度。

本项目用于教学和情景探索。模型参数、起点和模拟结果均为假设，不代表现实国家的实测值或经济预测。

## 本地使用

### 直接打开离线版

下载或克隆仓库后，双击 [downloads/poliscope-offline.html](downloads/poliscope-offline.html)，用现代浏览器打开即可。样式、脚本、十张图片和图片来源信息均已内嵌，可以断网使用。页面中的参考资料和摄影来源外链仍需联网访问。

[完整本地备份包](downloads/poliscope-local.zip) 同时包含离线版、原始源码、图片和使用说明。

### 运行原始源码

仓库根目录就是网站源码，无需安装依赖或构建。在该目录运行：

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。也可以直接双击根目录的 `index.html` 使用核心功能；本地 HTTP 服务可以确保“城市影像来源”正常读取 `photos/credits.json`。

进度保存在浏览器本地存储中。线上版与本地版的进度分别保存，不会自动同步。清除浏览器数据也会清除对应进度。

## 文件结构

```text
index.html             页面结构
app.css / atlas.css    页面样式
engine.js              模拟计算
models.js              制度案例与参考资料
atlas.js               制度图谱和模型说明
app.js                 工作台和交互
photos/                十张城市图片及来源信息
downloads/            单文件离线版与完整备份包
```

## 图片与资料来源

城市影像的作者、原始链接与许可名称保留在 [photos/credits.json](photos/credits.json)，也可在网站的“模型说明 → 城市影像来源”查看。图片署名与原有来源信息一并保留。

制度简介的参考链接保留在 `models.js` 和页面中，可点击查看原始资料。
